# 长征星火 · AI 长征讲解员

纪念中国工农红军长征胜利 90 周年 · 智绘长征创作大赛参赛作品

在线体验：https://jlk1209.github.io/

## 一句话

一个单文件、零依赖、离线为底、联网可选的红色文化智能体：同一套知识底座，四种交互人格——讲解员、红军战士、问答助手、活动策划。

## 形态与约束

- 单 HTML 文件，内联 CSS 与原生 JavaScript，约 4.3 MB / 5200 行，无外部脚本、无后端接口、无数据库。
- 拷到 U 盘、发到群里、放进离线大屏即可打开；断网可用。
- 联网为可选能力：填入自己的 API Key（DeepSeek／Kimi／智谱／通义等 OpenAI 兼容接口），浏览器直连服务商，在离线答案上追加一段带模型署名的改写；Key 只存本机，不填 Key 完全不联网，失败自动回退离线结果。
- 全部图画为内联 SVG 线描与明暗渲染，不使用生成式「史料照片」，不使用真实人物肖像，不使用 emoji。

## 四种模式

1. 路线讲解：点击 13 个站点，按「时间—现场—细节—意义」展开。
2. 人物对话：小石头、卫生员、宣传员、老班长四个虚构角色，换位讲述。
3. 智能问答：自由追问，覆盖长征史实、精神谱系、诗词、场馆、对手与转折事件，也答日常闲聊。
4. 任务规划：把一段路线排成可执行的研学方案，含行程、任务单与讲解词。

## 检索与可解释

- 混合检索：字符二元组 BM25 + 向量余弦 + 实体链接 + 知识图谱一跳。
- 知识库：6434 条、17 类（1282 条档案 + 5152 条问答卡）；474 条别名真值；图谱 1282 个档案节点。
- 问法归一：同义词表 + 可能问法索引 + 主题规则 + 变体让位；25 个主题 77 种说法 100% 命中、0 次兜底。
- 问法扩容（v15）：每条长征档案再挂 6 种问法（讲讲／咋回事／是啥／最要紧的是什么／为什么要了解／用三句话讲），问答卡 1150 → 5152；引擎直接识别口语问面（有啥用、好在哪、苦在哪、咋赢的、凭啥、谁打的、咋回事、说道说道等），同一件事七八个口子都能问进来。
- 问面语义：先判「问的是哪一面」——意义、胜因、教训、评价、代价、世界影响、讲法、过程、数字、时间、人物、故事、概念——再按面取字段；另有 8 条总述档案专答「整条长征」这类整体问题，问答卡在整体问题上主动让位。
- 六智能体流水线：路由 → 检索 → 图谱 → 核查 → 生成 → 守门，逐轮写入可查轨迹；联网模式下追加第 07 步「联网 Agent」。
- 零编造：库内无记载时明确说没有，并给出近邻建议，不伪装成史实。

## 语音播报

- 只播普通话：候选音色限定 zh-CN / cmn，粤语、台湾国语、外语与男声一律排除；优先自然女声，页脚「音色」可循环试听。
- 按句切分、句末停 420 毫秒、长句在逗号处断开；音调 0.95、默认 0.9× 语速，读得轻而慢。
- 「自动播报」默认开启，三档语速（0.9× / 1.0× / 0.8×），完全本地合成、不请求云端语音接口。
