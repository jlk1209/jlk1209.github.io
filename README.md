## 一句话

一个单文件、零依赖、可离线运行的红色文化智能体：同一套知识底座，四种交互人格——讲解员、红军战士、问答助手、活动策划。

## 形态与约束

- 单 HTML 文件，内联 CSS 与原生 JavaScript，约 725 KB / 3278 行，无外部脚本、无后端接口、无数据库。
- 拷到 U 盘、发到群里、放进离线大屏即可打开；断网可用。
- 全部图画为内联 SVG 线描与明暗渲染，不使用生成式「史料照片」，不使用真实人物肖像，不使用 emoji。

## 四种模式

1. 路线讲解：点击 13 个站点，按「时间—现场—细节—意义」展开。
2. 人物对话：小石头、卫生员、宣传员、老班长四个虚构角色，换位讲述。
3. 智能问答：自由追问，覆盖长征史实、精神谱系、诗词、场馆、对手与转折事件，也答日常闲聊。
4. 任务规划：把一段路线排成可执行的研学方案，含行程、任务单与讲解词。

## 检索与可解释

- 混合检索：字符二元组 BM25 + 向量余弦 + 实体链接 + 知识图谱一跳。
- 知识库：1122 条、16 类；474 条别名真值；图谱 1122 节点、9430 边、平均度 8.4。

- 零编造：库内无记载时明确说没有，并给出近邻建议，不伪装成史实。
